# Khalid — Business Growth & Automation

Bilingual portfolio and content workspace for Khalid Mohamad. The public site
supports ten complete visual directions, English and Arabic layouts, persistent
content in Cloudflare D1, media uploads in R2, and an owner-only admin area.

## Local development

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run lint
npm test
npm run db:generate
```

Public routes are `/en` and `/ar`. The protected design lab is `/designs`, and
the protected content workspace is `/admin`.
